# Cranial Non-metric Trait MMD Analysis

This repository contains the input data and R code used to reproduce the analyses reported in the manuscript.

The analyses assess the correspondence between cranial non-metric trait distances and genetic distances in two regional population sets: the Ural group and the Siberian group.

## Repository structure

```text
cranial-nonmetric-mmd-analysis/
  README.md
  run_mmd_honest_analysis.R

  data/
    ural_trait_frequencies.csv
    siberia_trait_frequencies.csv
    ural_fst_matrix.csv
    siberia_fst_matrix.csv

  results/
```

## Input data

The `data/` folder contains four input files:

- `ural_trait_frequencies.csv`  
  Frequencies of 30 cranial non-metric traits and sample sizes for the Ural population group.

- `siberia_trait_frequencies.csv`  
  Frequencies of 30 cranial non-metric traits and sample sizes for the Siberian population group.

- `ural_fst_matrix.csv`  
  Genetic distance matrix used for the Ural population group.

- `siberia_fst_matrix.csv`  
  Genetic distance matrix used for the Siberian population group.

## R script

The main analysis script is:

- `run_mmd_honest_analysis.R`

The script performs the following analyses:

- calculation of Mean Measure of Divergence (MMD) distances;
- Mantel tests between MMD and FST matrices;
- preliminary screening of trait subsets by subset size `k`;
- Honest permutation procedures with repeated trait reselection;
- fixed-size Honest analysis for `k = 12`;
- sequential expansion of the Honest core;
- leave-one-out checks.

During the leave-one-out analysis, trait sets are not reselected. The procedure evaluates the stability of the already selected trait panels after excluding one population at a time.

## How to run the analysis

Run the script from the repository root:

```r
source("run_mmd_honest_analysis.R")
```

The script writes output tables to the `results/` folder.

## Notes on reproducibility

The subset search uses fixed random seeds to reproduce the analyses reported in the manuscript. Because the number of possible trait combinations is very large, the subset search is based on fixed random samples of combinations.

Figures in the manuscript were prepared separately from the numerical output files generated by this script.

## Software requirements

The script was written for R and requires the following R package:

```r
Matrix
```

The package is loaded automatically by the script. If it is not installed, install it with:

```r
install.packages("Matrix")
```
